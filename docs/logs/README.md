# Work logs

One file per day, named `YYYY-MM-DD.md`. Each file lists what was done that date.

**How to use (see CLAUDE.md "Work log"):**
- Before starting a change, read the newest file here.
- After finishing a coding task, append a short bullet to today's file (create it if missing).
- Keep it scannable: milestone/area headings, one bullet per task with the commit
  short-sha, requirement IDs (FR-*/T-*/§), and a terse what/why. `[pkg]` tags work in
  the `unified-storage` repo.

Newest day first is fine; within a day, newest entry last.
